# 06 — 真实战斗 HUD 与手机触控

**What to build:** 将真实游戏状态接入战斗三分区 HUD，并保证手机操作可用。战斗左侧美术区只放标题与装饰；中央版面保持450×600逻辑坐标，右侧承载真实资源与机制状态。Lives/Bomb用离散资源格，一格一份，不增加残片或充能含义；Edit显示真实0–100进度。覆盖0/1/4/8、练习超过8、零Bomb、长分数、Letter接近0及Combo/Unstable/倾向并发，保留Boss标记等真实反馈。难度签和特殊模式标识分开。触控相对位移按实际显示盒映射，保留按下射击/松开停止、轻点/拖动、边界钳制和释放状态。手机常驻关键资源与状态，低频信息由08接入暂停页；本票先保证数据可用与当前可访问路径，不等待暂停视觉重做。

**Blocked by:** None — can start immediately

**Status:** implemented — 功能与结构验收完成；最终美术独立审核，PR 待审阅、不自动合并

- [x] 逻辑版面固定 450×600，显示等比缩放。按后续确认的画布优先自适应：桌面允许放大，竖屏按可用宽度显示，HUD 下置且可滚动访问，不为首屏容纳 HUD 压缩画布；触控继续按实际显示盒映射。
- [x] Lives/Bomb 一个亮格一份资源，不添加残片百分比或充能含义；Edit 则必须显示真实0–100进度。标签、数量和颜色同时表达含义，Lives紫红、Bomb绿色、Edit青蓝。
- [x] 0/1/4/8 与练习 >8 的起始残机准确显示，不画无限长度格子；零 Bomb、Edit 未满/已满各自可辨。
- [x] Score/HiScore/Combo 用稳定等宽数字，长分数与倒计时可读；值变化读数及时更新，不延迟真实扣除后的读数。
- [x] Letter 名称、剩余时间、收取奖励、当前卡进度在版面上沿集中；Boss标记与真实实时反馈不丢失。章节开始/结束横幅和演出由11负责，协调层级而不重复实现。
- [x] 难度签显示实际难度，Replay/Nomiss/Practice 为独立小标识，与难度档分离。
- [x] 桌面三分区成立，左侧美术区不含动态游戏数据；中央版面不被装饰遮挡弹幕或碰撞区。
- [x] 手机保留 Lives/Bomb/Edit/压缩 Score/Letter 计时/当前 Unstable/累计与章内倾向，Combo 仅有效时显示；后续选择“画布 + 下方 HUD”，较矮视口允许滚动访问 HUD 与按钮，不再要求全部信息同屏；低频信息保留详情入口。
- [x] 触控相对滑动、边界钳制、轻点 vs 拖动、按下射击/松开停止、取消/失焦释放按住均正确。
- [x] Item/Bomb 触控按钮保持单次动作语义；Pause 不因 pointer/touch 双重事件立即开关两次。
- [x] HUD 更新复用实际数据变化与绘制时机，不做每帧 DOM 重建；变化动画不阻塞连续输入。
- [x] 桌面/手机已与指定截图对照检查结构与可玩性；后续用户要求画布优先，其他战斗 UI/HUD 外观留到最后微调。该项不代表最终视觉或人物美术批准。

**规格覆盖：** ID-05、ID-06、ID-07、ID-08；US27–US37、US65；T05、T06、T07、T18、T20。

**协调事项：** 本票保留实际低频字段取值并给08消费；08负责新的暂停布局。在08落地前，现有暂停动作仍可运行，不通过删除唯一可见读数交付中间态。与11约定持续HUD与短暂章节横幅的层级；只就共享变更协调，不强加新的阻塞边。
