## 已接受的目标

- 高相似度贴近 th14 + th18，以实际参考截图为依据。th14主导题字、描边字形、非对称外围构图；th18主导多色层叠与华饰组织。东方梦无垠仅辅助战斗舞台、HUD分区和资源组织。
- 中央版面为首要视觉主体，外围非对称；HUD保留分组清楚的战斗仪表簿结构，使用游戏内字形、资源符号、纹样与状态反馈。
- 高密度华饰与可读性平衡；仅HiScore、Player、Chapter、Bonus等低频信息可弱化，关键字段与版面必须清楚。
- 使用本项目标题“棍維何意味”、真实角色名、难度、模式和资源数据。撤掉原型的虚构标题、EDIT A3、虚构模式等内容。
- 手机采用同一视觉语言。减少网页默认控件、卡片分隔与点虚线装饰；不把CSS技术或原生HTML语义本身视为问题，也不擅自删除有玩法含义的线条。
- 不复制原作角色、标题、商标、剧情文字或整张截图；不新增未经确认的最终人物素材。

## 保持的行为

450×600逻辑版面与3:4显示比例、真实触控映射、玩法数值和存档契约不变。Score、Lives、Bomb、Edit、Letter、难度、模式、Unstable、Tendency、资源颜色与离散资源格、暂停/操作入口保持正确可读；装饰不遮挡自机、敌人或弹幕。保留06已验证的释放、单次动作和窄屏滚动语义。

## 单一完整画面验收

1. 直接打开现有 th14/th18 参考截图，以其实际视觉关系修订生产战斗页；不重新开展方向选择或泛化访谈。
2. 3000端口展示该独立实现工作树中的完整真实战斗页面，核对HTTP服务CWD和实际加载来源；不继续用四卡片预览代表进度。
3. 以同视口实际战斗截图验证主体位置、占位、题字/HUD层级、Letter与ENEMY边界和关键数据可读性。至少覆盖1365×900、1264×625、390×844、320×568；手机同时检查顶部画布和滚动后的操作区。
4. 运行适合改动的HUD/触控验证与项目要求检查，进行代码审查，同步AGENTS/README。功能通过与用户视觉认可分别报告。
5. 提交独立功能PR供审阅；不自动合并PR #33或本票PR。
