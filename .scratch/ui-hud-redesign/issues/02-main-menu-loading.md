# 02 — 主菜单、加载与入场演出

**What to build:** 重做主菜单为完整的东方式标题画面，保留现有菜单编排。左上为艺术主标题 **棍維何意味**，其下小型英文副标题 **OTTOWiki Project**；左下为十项直达导航，顺序 Start Game、Extra Start、Stage Select、Practice、Ranking、Replay、Manual、History、Settings、Exit，按间距与层级分组，不新增子菜单。右侧为饮泉思源单人主体（结构阶段可占位）。视觉以浅纸水墨为基线，借 th14 非对称标题/人物/菜单构图与纹样拼贴，以 th18 多色碰撞、装饰叠层与展示字形加强，用纸墨远近与笔刷层做出比第三版更迷幻、华饰的层次，不得收敛回极简米色网页。艺术主标题保持已定汉字，导航短词英文主、中文辅；装饰、人物与墨层不拦截点击。

**Blocked by:** None — can start immediately

**Status:** implemented — 本票功能与结构验收通过；人物及最终美术独立审核

- [x] 正式浏览器启动后标题「棍維何意味」与副标题 OTTOWiki Project 正确呈现，十项入口全部可见且逐项可达，点击/按键能进入对应页面，无新增代码错误。
- [x] 首次进入主菜单播放完整分层绘画入场演出；演出任何阶段按确认键或点击立即跳到稳定完成态，且该次跳过输入被消费，不额外激活当前焦点选项。
- [x] 从任一子页面返回主菜单时重播完整入场演出；返回后焦点保留上次选择项，选项切换与执行不再触发主菜单入场演出。
- [x] 键盘方向键/WASD 单次移动只改变焦点，Enter/Z/Space 确认，Esc/X 返回；鼠标命中区域与可见控件一致，点击不会穿透到装饰层。
- [x] 触屏点击与确认路径清晰，单次输入不会误触发下一状态；演出期间第一次点击只跳过。普通主菜单入口沿用已确认的直达操作，不把路线页的“先选中再确认”扩大为全部菜单必须点两次。移动竖屏独立排版，标题、导航、返回与角色主体不被裁切或遮挡。
- [x] reduced-motion 开启时直接进入稳定呈现态，不播放装饰性移动，且所有信息与导航保持可用。
- [x] 真实等待资源才显示 Loading；进度只在可真实测量时显示。加载失败给出可理解反馈与既有恢复路径，不显示假进度条、不永远停留在假进度画面。
- [x] Exit 复用当前平台能兑现的退出/返回行为，给出清晰反馈，不留下无效按钮、不强行关闭浏览器。
- [x] 主标题优先日式汉字字形，台湾繁体仅作标题缺字兜底；导航与HUD短词以外的中文不全局英文化或转繁体。与参考截图并排检查游戏标题画面构图、选中态和装饰层次；该视觉认可不代表最终人物素材已通过。
